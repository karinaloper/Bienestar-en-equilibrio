# Bienestar en equilibrio

Sitio de **Karina López, Health Coach**, y del **Método RAÍZ**, una experiencia educativa de cuatro semanas para escuchar las señales del cuerpo, cuidar la alimentación y construir hábitos sostenibles.

[Visitar el sitio](https://karinaloper.github.io/Bienestar-en-equilibrio/) · [Instagram @heka.karina](https://www.instagram.com/heka.karina/)

## Qué encontrarás

- **Método RAÍZ.** Cuatro etapas para trabajar tus hábitos: Reconocer, Alimentar, Integrar y Zarpar.
- **Servicios.** Asesorías privadas, clases y talleres, bebidas fermentadas y eventos privados.
- **Recursos.** Cuaderno y recetario RAÍZ, material sobre bienestar digestivo y una guía de fermentados para principiantes. La guía muestra un precio de **$5.99 USD** y tiene una descarga de prueba sin cobro para cuentas con acceso al PDF en Google Drive.

## Editar y probar la página

El sitio es estático y se publica con **GitHub Pages** desde la raíz de la rama `main`.

| Archivo | Contenido |
| --- | --- |
| [`index.html`](index.html) | Textos, enlaces y estilos de la página |
| [`bienestar.jpg`](bienestar.jpg) | Fotografía de portada |
| [`favicon.png`](favicon.png) | Icono del sitio |

Para revisar cambios en tu computadora, clona el repositorio y abre `index.html` en tu navegador.

```sh
git clone https://github.com/karinaloper/Bienestar-en-equilibrio.git
cd Bienestar-en-equilibrio
```
